## 前言
#### 中国人常畅想“上天入海”。如果“天”的定义是地球的大气层边界的话，可以说我们目前是“上天容易入海难”。相应的，大气的观测较为容易，从气球、飞机、雷达到卫星，基本达到了“透明大气”的程度，我们可以知道台风往哪边跑，风往哪边吹。与之相比，海洋的观测难度太大了，最主要的原因是海洋深不见底，字面意义的我们的眼睛看不到海洋底部。目前我们可以通过卫星获取海表流场的信息，但是500m,1000m,2000m,4000m海洋长什么样子，目前还是依赖观测。最近发现了一个有意思的现象，但是老板觉得还是可以先放一边主攻别的问题。因为才刚刚学会怎么下载数据，短期内还要冷落它，为了方便后续快速捡起来，先备份一下处理过程。

## 1. 什么是Argo计划？
![Argo示意图(来自官网)](https://argo.ucsd.edu/wp-content/uploads/sites/361/2020/06/float_cycle_1-1536x848.png)

[`Argo`](https://argo.ucsd.edu/) (Array for Real-time Geostrophic Oceanography) 自2000年正式启动。它通过投放数千个具备剖面测量能力的自动浮标，构建了一个覆盖全球不冻海域的实时监测网络。与传统的船舶定点观测相比，`Argo`的核心优势在于其全天候、高频次、低成本的自主采集能力。

`Argo` 浮标之所以被称为**海洋机器人**，核心在于其精巧的浮力调节系统与预设任务周期。一个典型的观测循环通常持续 10 天，分为以下四个阶段：
 - 下潜阶段（Descent）： 浮标通过内置的液压泵将液压油从外部油囊抽回壳体内部，减小排水体积。由于整体密度超过海水，浮标开始缓慢下潜。它通常会下降并稳定在约 1000 米的“漂流深度”（**Parking Depth**）。
 - 随流漂移（Drift）： 浮标在预设深度随深层洋流漂移约 9 天。这一阶段的数据对于研究深层大尺度环流（如地转流）具有极高的科研价值。
 - 剖面测量（Profile）： 随后，浮标继续下潜至 2000 米（深海型则更深），然后启动上浮程序。在上升过程中，传感器以高频率连续采集不同压力层位的温度和盐度数据，形成一条垂直“剖面”。
 - 卫星传输（Data Transmission）： 浮标浮出水面后，天线自动弹出，通过 `Iridium`（铱星）或 `Argos` 卫星系统将定位信息和采集到的剖面数据实时传回地面数据中心。完成传输后，浮标再次压载，开启下一个循环。

这种“循环往复”的设计使得单台浮标在无需人为干预的情况下，能够持续工作 4 到 5 年，直到电池耗尽。得益于`Argo`计划，目前已基本实现针对海洋上层（0-2000m）的全海域覆盖。

![DELIVERING OCEAN DATA: This map shows positions of the nearly 4000 Argo floats that have delivered data within the last 30 days. Credit: NOAA](https://th.bing.com/th/id/OIP.pCL44BM4Uy1Ow4ZZaMVs-QHaDY?w=348&h=159&c=7&r=0&o=7&dpr=1.5&pid=1.7&rm=3)

## 2. 什么是Deep Argo 计划?
如果说标准 `Argo` 计划让我们看清了海洋表层的“皮肤”与“浅层肌肉”，那么  [`Deep Argo`](https://argo.ucsd.edu/expansion/deep-argo-mission/) 则是将触角伸向了海洋的“核心”。`Deep Argo` 是国际 Argo 计划的战略扩展，旨在将其观测深度从传统的 2000 米向下延伸至 4000 米甚至 6000 米。由于全球海洋约 50% 的体积位于 2000 米以下，`Deep Argo` 的目标是实现对全海深（Full-depth）海洋属性的长期、连续监测，填补深层大洋观测的空白。
对于地球科学研究而言，深海并非静止的死水，它在气候系统中扮演着至关重要的角色：
 - 捕捉“消失的热量”： 随着温室效应加剧，地球积聚了大量额外热量，其中约 **90%** 被海洋吸收。研究表明，相当一部分热量正向深海转移。若缺乏深海观测，我们将无法准确闭合全球能量收支平衡，进而导致气候预测出现偏差。
 - 监测底层水（AABW）的演变： 比如源自南极的南极底层水 (AABW)。它是驱动全球深层经向翻转环流的关键力量。近年来的零星观测显示，深层大洋正在变暖且淡化，`Deep Argo` 是追踪这些深远影响、评估深层洋流长期趋势的唯一大规模手段。
 - 海平面上升的深层贡献： 海平面上升不仅源于冰川融化，还源于海水的热膨胀。深海变暖导致的海水膨胀是海平面上升的重要组成部分，深海数据能显著提升我们对未来海平面变化的预测精度。

要让浮标在 **6000** 米深、承受约 **600** 个大气压（相当于一头成年大象踩在你的脚趾上）的环境下生存并工作，需要攻克极高的工程技术壁垒：
 - 新型耐压壳体： 传统的铝合金壳体在深海高压下会产生形变甚至崩塌。深海 Argo 采用了更坚固的强化玻璃球或特殊高强度复合材料作为压力壳，不仅抗压，且能保持较轻的自重以维持浮力。
- 高精度深海传感器： 在高压环境下，传感器的电导率电极和压力传感器容易发生微小形变，导致数据漂移。深海 Argo 配备了专门标定的高压传感器（如`SBE-61`），能够在极端的物理条件下保持毫秒级的精度。
 - 优化的浮力驱动系统： 深度越深，液压系统往外排出液压油所需的功率就越大。深海浮标优化了电池能量管理系统和高压液压泵，确保其在数千米的垂直航行中依然拥有充足的续航能力（通常可完成约 100-150 个循环）。

目前全球正在运行的深海 Argo 浮标总数约为 200-250 个，主要分布在南大洋、北大西洋和西太平洋的部分海盆。

## 3. 下载并处理 Deep Argo 数据
`Deep Argo`可在多个平台下载，目前我的思路是结合**网页交互**和**http数据节点**来下载：

 - 首先在网格交互网站，如[中国Deep Argo网站](http://deep.argo.org.cn/#/)或者[欧洲Deep Argo网站](https://fleetmonitoring.euro-argo.eu/dashboard)先确定自己所选区域，并确定某个浮标的`WMO`编号（如`7901137`）。随后可确定该浮标的所属单位是`AOML`。
 - 随后进入[**http数据节点**](https://data-argo.ifremer.fr/)网站，并进入子文件夹`dac/`,该文件夹是依据浮标数据单位进行区分的，随后在里面找寻`aoml/`子文件夹，并搜寻进入`7901137/`文件夹，并下载数据。

随后我们可分析数据，下文以使用python画浮标轨迹为例：
```python
# %%
import os
from glob import glob
import numpy as np
import xarray as xr

import cartopy.crs as ccrs
import cartopy.feature as cfeature
import matplotlib.pyplot as plt
import cmocean

# %%
topo_ds = xr.open_dataset("../data/TOPO/ETOPO1_Bed_g_gdal.grd")
topo = topo_ds["z"]
nx, ny = topo_ds["dimension"].values  # 网格数量
dx, dy = topo_ds["spacing"].values  # 网格间距
x0, y0 = topo_ds["x_range"][0].values, topo_ds["y_range"][0].values

lon = x0 + dx * np.arange(nx)
lat = y0 + dy * np.arange(ny)

topo_2d = topo.values.reshape((ny, nx))

topo_2d = topo_2d[::-1, :]

topo_xr = xr.DataArray(
    topo_2d,
    coords={"lat": lat, "lon": lon},
    dims=["lat", "lon"],
)
topo_indian = topo_xr.sel(lon=slice(60, 140), lat=slice(-70, -40))
new_lon = np.arange(60, 140.1, 0.1)
new_lat = np.arange(-70, -39.9, 0.1)
topo_01 = topo_indian.interp(lon=new_lon, lat=new_lat, method="linear")

# %%
fig = plt.figure(figsize=(12, 8), dpi=150)
ax = plt.axes(projection=ccrs.PlateCarree())
ax.set_extent([60, 140, -70, -45], crs=ccrs.PlateCarree())  # type: ignore

contourf = ax.contourf(
    topo_01.lon,
    topo_01.lat,
    np.abs(topo_01),
    levels=np.arange(0, 5000, 100),
    transform=ccrs.PlateCarree(),
    zorder=1,
    cmap=cmocean.cm.deep_r,  # type: ignore
    extend="both",
)

ax.add_feature(cfeature.LAND, facecolor="lightgray", zorder=2)  # type: ignore
ax.add_feature(cfeature.COASTLINE, linewidth=0.5, zorder=3)  # type: ignore
ax.gridlines(draw_labels=True, dms=True, x_inline=False, y_inline=False)  # type: ignore

data_dir = "../data/deep_argo/"

file_pattern = os.path.join(data_dir, "*7901137*traj.nc")
file_list = glob(file_pattern)

print(f"共检索到 {len(file_list)} 个轨迹文件，开始批量绘制...")

for index, file_path in enumerate(sorted(file_list[:6])):
    file_name = os.path.basename(file_path)
    wmo_id = file_name.split("_")[0]

    try:
        # 读取单个浮标数据
        sub_ds = xr.open_dataset(file_path)

        lon_raw = sub_ds.LONGITUDE.values
        lat_raw = sub_ds.LATITUDE.values

        # 核心清洗：剔除无效点
        mask = ~np.isnan(lon_raw) & ~np.isnan(lat_raw)

        # 如果文件里没有有效定位点，跳过
        if not np.any(mask):
            print(f"浮标 {wmo_id} 无有效定位数据，已跳过。")
            continue

        lon_track = lon_raw[mask]
        lat_track = lat_raw[mask]

        
        lon_track = lon_track[1:]
        lat_track = lat_track[1:]
        (line,) = ax.plot(
            lon_track,
            lat_track,
            linewidth=5.0,
            alpha=0.7,
            transform=ccrs.PlateCarree(),
            zorder=4,
            label=f"Float {wmo_id}",
        )

        # 唯美标注该浮标的起点(○)和终点(×) —— 采用与线相同的颜色
        line_color = line.get_color()
        ax.plot(
            lon_track[0],
            lat_track[0],
            marker="o",
            color=line_color,
            markersize=15,
            transform=ccrs.PlateCarree(),
            zorder=5,
        )
        ax.plot(
            lon_track[-1],
            lat_track[-1],
            marker="x",
            color=line_color,
            markersize=20,
            markeredgewidth=5,
            transform=ccrs.PlateCarree(),
            zorder=5,
        )

    except Exception as e:

colorbar = plt.colorbar(contourf, ticks=np.arange(0, 5001, 1000))
colorbar.ax.set_title("(m)", size=13)
plt.title(f"Trajectory of Deep Argo", fontsize=12)
plt.legend(loc="lower left")
ax.set_aspect("auto")

plt.tight_layout()
plt.show()
```

## 1. 为什么选择MITgcm?
![MITgcm空间尺度适应范围(来自官网)](https://mitgcm.readthedocs.io/en/latest/_images/scales.png)

当今物理海洋研究中，CROCO（基于 ROMS 框架）和 MITgcm 都是极其优秀且主流的数值模式，但两者在设计哲学上存在根本性差异：
| 对比维度 | MITgcm | CROCO (ROMS 谱系) | 科研适用性考量 |
| :--- | :--- | :--- | :--- |
| **动力学** | **支持非静力学** | 仅支持**静力学近似** | 深对流、亚中尺度等，非静力学是刚需。 |
| **垂直坐标** | 采用 **z坐标** | 采用**地形跟随坐标 ($s$-坐标 / $\sigma$-坐标)** | $z$-坐标在深海大洋更精准；$s$-坐标在浅海、陆架区表现更佳。 |
| **地形处理** | **极佳**。Partial Cell 克服了传统 $z$-坐标的锯齿效应，无要强梯度误差。 | **较弱**。在深海陡峭地形（如海岭、海沟）处，易引入显著的**压强梯度力误差**。 | 决定了模式在深海复杂地形环流（如南极绕极流穿过海岭）中的保真度。 |
| **伴随模式<br>(Adjoint Model)** | **原生高度支持**。底层代码专为 TAF 自动微分工具优化。 | 缺乏原生系统性支持。 | 如果科研涉及**参数同化、状态估计（如 ECCO）或反向敏感性分析**，MITgcm 具统治地位。 |
| **研究尺度** | 从高分辨率区域到全球大洋环流。 | 侧重于区域、近岸、陆架及边缘海的高分辨率模拟。 | 自行决定 |

因为我最终目标是针对南大洋大地形下大尺度环流与锋面、中尺度涡之间作用关系，**仅对我而言**，MITgcm是最优解。

## 2. MITgcm demo 试验配置过程

### 2.2.1 修改`code/SIZE.h`文件
该文件有简要介绍，我们重点关心`sNy`,`sNx`,`nSx`,`nSy`,`nPx`,`nPx`6个参数，其共同决定了模型的总网格数（`Nx`, `Ny`）。我们这里不做修改。简要说，该信息是告诉计算机如何配置计算资源。
```
...
...
C     Voodoo numbers controlling data layout:
C     sNx :: Number of X points in tile.
C     sNy :: Number of Y points in tile.
C     nSx :: Number of tiles per process in X.
C     nSy :: Number of tiles per process in Y.
C     nPx :: Number of processes to use in X.
C     nPy :: Number of processes to use in Y.
C     Nx  :: Number of points in X for the full domain.
C     Ny  :: Number of points in Y for the full domain.
C     Nr  :: Number of points in vertical direction.
...
...
      PARAMETER (
     &           sNx =  62,
     &           sNy =  62,
     &           OLx =   2,
     &           OLy =   2,
     &           nSx =   1,
     &           nSy =   1,
     &           nPx =   1,
     &           nPy =   1,
     &           Nx  = sNx*nSx*nPx,
     &           Ny  = sNy*nSy*nPy,
     &           Nr  =   1)
     
...

```
### 2.2.2 修改` input/data`文件
`input/data` 是控制模式运行最重要的参数文件。它采用`Fortran`的`Namelist`语法格式，主要由五个核心参数块（Namelist Block）组成。我们在跑示例时，只需重点修改第三部分（时间步长）。
#### 1.物理参数区（&PARM01）— 保持默认。
```
# Continuous equation parameters
 &PARM01
 viscAh=4.E2,
 f0=1.E-4,
 beta=1.E-11,
 rhoConst=1000.,
 gBaro=9.81,
 rigidLid=.FALSE.,
 implicitFreeSurface=.TRUE.,
# momAdvection=.FALSE.,
 tempStepping=.FALSE.,
 saltStepping=.FALSE.,
 &
 ```
#### 2.二维椭圆求解器参数（&PARM02）— 保持默认
此部分控制压力求解器的收敛精度，主要用于自由表面高度的隐式求解。
 ```
 # Elliptic solver parameters
 &PARM02
 cg2dTargetResidual=1.E-7,
 cg2dMaxIters=1000,
 &
 ```
#### 3.时间步长参数区（&PARM03）— 重点修改
官方代码中，总步数 nTimeSteps 仅设为 10。这是为了供MITgcm官方进行快速自动化测试使用的。如果你想要跑出漂亮的模拟结果，需要把`nTimeSteps=10`前面加#注释掉，然后把下方`nTimeSteps=77760` 和`monitorFreq=864000.`前#删掉。

 ```
 # Time stepping parameters
 &PARM03
 nIter0=0,
 # nTimeSteps=10,
 deltaT=1200.0,
 pChkptFreq=31104000.0,
 chkptFreq=15552000.0,
 dumpFreq=15552000.0,
 # monitorFreq=1200.,
 monitorSelect=2,
 #-for longer run (3.0 yr):
 nTimeSteps=77760,
 monitorFreq=864000.,
 &
 ```
#### 4.网格几何参数区（&PARM04）— 保持默认
 ```
 # Gridding parameters
 &PARM04
 usingCartesianGrid=.TRUE.,
 delX=62*20.E3,
 delY=62*20.E3,
 xgOrigin=-20.E3,
 ygOrigin=-20.E3,
 delR=5000.,
 &
 ```

#### 5.输入外部驱动场（&PARM05）— 保持默认
 ```
 # Input datasets
 &PARM05
 bathyFile='bathy.bin'
 zonalWindFile='windx_cosy.bin',
#zonalWindFile='windx_siny.bin',
 meridWindFile=,
 &
 ```
# 3 运行模式
## 3.1 编译和配置代码
```
cd build
../../../tools/genmake2 -mods ../code ««-of my_platform_optionFile»»
make depend
make
cd ..
```
命令中的 `-of`用于指定平台配置文件。这些文件存放在 `tools/build_options/` 目录下。我们需要根据自己使用的服务器或超算环境，挑选最匹配的文本。我用的是`linux_amd64_ifort+impi`文本，代表操作系统是`linux`,cpu架构是`amd64`，Fortran 编译器是`ifort`,可执行并行通信库`+impi`。需要注意的是，官方自带的 `linux_amd64_ifort+impi` 文本中，默认指定的 C 编译器（CC）是老版本的 `icc`。然而，在新版 Intel 环境中，`icc` 已经被官方弃用并全面替代为 `icx`。需要手动修改
``` bash
CC=icx
```
## 3.2 执行代码
执行一下代码，并在`run/`文件夹下得到后缀`.meta`（元数据描述）和`.data`（二进制数据）的文件。
```
cd run
ln -s ../input/* .
ln -s ../build/mitgcmuv .
./mitgcmuv > output.txt
```

## 2.4 读取输出数据
### 2.4.1 传统`MITgcmutils`
官方文档推荐的经典方案是使用官方自带的 `MITgcmutils` 工具包。以下是读取并绘制海平面高度代码:
```
from MITgcmutils import mds
import numpy as np
import matplotlib.pyplot as plt
XC = mds.rdmds('XC')
YC = mds.rdmds('YC')
Eta = mds.rdmds('Eta', 77760)
plt.contourf(XC/1000, YC/1000, Eta, np.linspace(-0.02, 0.05,8), cmap='hot_r')
plt.colorbar()
plt.show()
```
![模式输出海平面（来自官网）](https://mitgcm.readthedocs.io/en/latest/_images/full_solution.png)

### 2.4.2 现代科研平替`xmitgcm`
虽然官方的`MITgcmutils` 能用，但在大数据量、多维度的现代气候大模型分析中，它显得落伍。因为它读出来的只是“裸露”的 numpy 数组，你必须手动去剥离和记忆每一个维度的意义。目前学术界更推荐使用 `xmitgcm`。它能将模式输出直接封装进现代地球科学核心库 `xarray` 中，自动加载所有的经纬度、深度坐标以及物理单位，支持按时间或空间切片（Slicing）进行流式计算。

但是需要注意的是，`xmitgcm`在解析目录时，默认要求网格文件名必须是小写（如 `xc.data`），且必须包含一份标准的网格描述。为了能让 `Python` 顺利认出数据，我们需要在运行前对 `input/data` 文件的 `&PARM01` 块进行信息添加：
```
 useSingleCpuIO=.TRUE.,

```
我们这里将驱动风场由Cos形改为Sin形，并重新运转模式。
针对`input/data`，修改`&PARM04`：
```
# Input datasets
 &PARM05
 bathyFile='bathy.bin'
 # zonalWindFile='windx_cosy.bin',
 zonalWindFile='windx_siny.bin',
 meridWindFile=,
 &
```
随后终端执行：
```
 rm -f *.meta *.data
 ./mitgcmuv > output.txt 2>&1 &
```

随后画出gif图片：
```
#%%
import os
import matplotlib.animation as animation
import matplotlib.pyplot as plt
import numpy as np
import xmitgcm
# ==========================================
# 1. Parameters
# ==========================================
data_dir = "/MITgcm/verification/tutorial_barotropic_gyre/run/"
output_gif = "mitgcm_eta_evolution.gif"
my_prefixes = ["Eta"]
# ==========================================
# 2. load data
# ==========================================
ds = xmitgcm.open_mdsdataset(
    data_dir=data_dir,
    geometry="cartesian",
    nx=62,
    ny=62,
    delta_t=1200,
    prefix=my_prefixes,
    ignore_unknown_vars=True,
    ref_date="0001-01-01 00:00:00",
)

X_km = ds.XC.isel(XC=slice(1, -1)) / 1000
Y_km = ds.YC.isel(YC=slice(1, -1)) / 1000
eta_all = ds["Eta"].isel(XC=slice(1, -1), YC=slice(1, -1))
num_frames = len(ds.time)

# ==========================================
# 3. figure intital
# ==========================================
fig, ax = plt.subplots(figsize=(8, 6))
v_min, v_max = float(eta_all.min()), float(eta_all.max())
if abs(v_max - v_min) < 1e-5:
    v_min, v_max = -0.01, 0.05
levels = np.linspace(v_min, v_max, 30)
contour = ax.contourf(
    X_km, Y_km, eta_all.isel(time=1), levels=levels, cmap="RdBu_r"
)
cbar = fig.colorbar(contour, ax=ax, label="Sea Surface Height (m)")
ax.set_xlabel("X (km)")
ax.set_ylabel("Y (km)")

# ==========================================
# 4. gif create
# ==========================================
def update(frame):
    for coll in ax.collections:
        coll.remove()
    current_eta = eta_all.isel(time=frame)
    current_time_step = int(ds.iter.isel(time=frame))
    ax.contourf(X_km, Y_km, current_eta, levels=levels, cmap="RdBu_r")
    ax.set_title(
        f"Barotropic Gyre Evolution - Time Step: {current_time_step:06d}",
        fontsize=12,
    )
    return (ax,)

# ==========================================
# 5.save gif
# ==========================================
ani = animation.FuncAnimation(
    fig, update, frames=num_frames, interval=10000, blit=False
)
ani.save(output_gif, writer="pillow", fps=5)

plt.close()
```

## 1本地电脑如何连接超算？
一般情况下，我们是通过个人电脑连接到超算上，然后使用超算的计算资源进行计算。连接两者的桥梁一般是`SSH`(Secure Shell)，它能够兼顾加密安全、命令行操作、文件传输、权限极简等优势，已被大家广泛接受。不管是Windows、Linux、MacOS系统，其终端中均自带`SSH`功能。最简单的方法是利用电脑终端连接超算：
```
ssh 你的用户名@超算指定节点域名IP
```
回车执行命令后提示
```
Are you sure you want to continue connecting (yes/no)?
```
输入`yes`回车，然后输入**超算登录密码**，回车即可登录。

## 2为何选择免密登录？
上文描述的命令行登录超算的方法是最简单的，但是真实情况中，我们一般会使用VScode等平台来登录超算，方便文本、代码的编辑和预调试。这时候我们通常更希望使用免密登录，原因有两点：如果密码登录，那么每次切换文件夹可能都需要重新输入密码，无效重复工作过多；2如果你偶尔挂机或者网络不佳，必须重新登录一次而不是点击`Reload windows`即可。所以，为了提高效率和保证身心健康，选择免密登录是最好的。

## 3如何免密码登录？
1. 如果超算平台管理不严格的话，可以在个人电脑终端自创建私钥和公钥，然后把公钥上传到超算平台个人账户`.ssh/`文件夹下
```
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519
```
然后将`id_ed25519.pub`文件上传超算平台用以免密登录的指定位置（这时候需要输入真实的登录密码一次）。

2. 如何超算管理严格，则只能在超算指定平台生成私钥`id_ed25519`和证书`id_ed25519-cert.pub`，随后将私钥和证书放置在本地`.ssh/`文件夹下即可。

为进一步简化登录过程，可在本地`.ssh/`文件夹下设置`config`文件，在其中指定登录节点的相关信息

1. 对于私钥和公钥的情况，可编辑：
```
Host 超算节点备注名
  HostName 超算指定节点域名IP
  ForwardAgent yes
  User 你的用户名
  IdentityFile ~/.ssh/id_ed25519
  ForwardX11 yes
  ForwardX11Trusted yes
```

2. 对于私钥和证书的情况，可编辑：
```
Host 超算节点备注名
  HostName 超算指定节点域名IP
  User 你的用户名
  IdentityFile ~/.ssh/id_ed25519
  CertificateFile ~/.ssh/id_ed25519-cert.pub
  IdentitiesOnly yes
```
通过上述配置，我们即可免密登录超算。过程很简单，但是好记性还是不如烂笔头啊。
